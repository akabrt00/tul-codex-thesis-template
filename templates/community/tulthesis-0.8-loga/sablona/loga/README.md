# PDF značky podle součástí TUL

Plný projekt obsahuje všechny původní značky. Složka `TUL/` obsahuje společné univerzitní značky; `FM/`, `FS/`, `FT/`, `FP/`, `EF/`, `FUA/`, `FZS/` a `CXI/` obsahují značky příslušných součástí.

Fakultu nastavujte jako dosud v `main.tex`, například `\documentclass[FM,BP]{tulthesis}`. Vyhledávání souborů nastavuje `nastaveni/cesty-loga.tex`, který načítá zavaděč šablony i společné nastavení balíčků. Názvy a obsah původních PDF se nemění; vlastní obrázky patří do `obrazky/`.
