# Visual decision tree

## Start with the communication need

| Need | Preferred form | Avoid |
|---|---|---|
| Compare quantities, trends, uncertainty, or distributions | PGFPlots graph or compact table | Decorative infographic, generated data |
| Explain steps, states, dependencies, or information flow | TikZ flow/process diagram | Screenshot of prose or a dense application UI |
| Explain physical components or connections | Simplified TikZ schematic; sourced technical drawing when exact geometry matters | Photorealistic invention presented as the real apparatus |
| Show material appearance, surface, specimen, location, or real setup | Verified photograph with provenance | AI-generated substitute presented as observation |
| Preserve an author's established model or taxonomy | Cited reproduction when permitted, otherwise a cited redraw | Unattributed tracing or superficial restyling |
| Demonstrate software operation | Reproducible screenshot with version/context | Cropped UI without identifying the state shown |
| Orient the reader across categories or a chapter structure | Small hierarchy, matrix, or map | Diagram that merely repeats headings |

## Decide whether to reuse or redraw

- Reproduce when the visual form itself is evidence, exact visual comparison matters, and permission permits reuse.
- Crop when irrelevant page surroundings can be removed without losing scale, legend, caption context, or qualifications.
- Redraw when the concept is important but the source is illegible, stylistically inconsistent, unavailable at useful quality, or not reusable. Cite the source of the structure and facts.
- Create from scratch when the synthesis, process, or architecture is specific to this project and fully supported by project evidence.
- Generate a raster illustration only when a non-evidentiary depiction is appropriate and deterministic TikZ/vector construction would not communicate the intended appearance.

## Academic stop conditions

Stop and request a decision when:

- reuse rights or confidential content are materially unclear;
- a crop would remove an important caveat, legend, scale bar, watermark, or attribution;
- adaptation might change scientific meaning;
- the visual requires invented geometry, values, units, labels, or causal relationships;
- generated imagery could be mistaken for actual observations or equipment;
- two visual forms imply different claims or levels of precision.
