# Template for a source content map

Create one map under `zdroje/90_zpracovane/poznamky-a-souhrny/` named `SRC-NNNN_<citacni-klic>_mapa-obsahu.md`. Paraphrase; do not copy long passages. Every factual pointer must retain the physical PDF page number.

```markdown
# Mapa obsahu: SRC-NNNN — Název

- Citační klíč: `...`
- Originál: `zdroje/...`
- Extrakční manifest: `zdroje/.../manifest.json`
- Stav kontroly: `[strojově extrahováno / vizuálně ověřeno / částečně ověřeno]`

## Rozsah zdroje

Stručně popiš účel, druh důkazů, časové a věcné pokrytí.

## Hledací větve

| Téma | Synonyma a hledané výrazy | Stránky | Co lze doložit | Druh důkazu |
|---|---|---|---|---|
| ... | ... | ... | ... | definice / metoda / výsledek / tabulka / doporučení |

## Klíčová tvrzení

| ID tvrzení | Přesná parafráze | Stránky | Síla opory | Poznámka |
|---|---|---|---|---|
| `CLM-SRC-NNNN-001` | ... | ... | přímá / nepřímá / omezená | ... |

## Struktura dokumentu

- strany ...: ...

## Omezení a mezery

- Uveď, co zdroj neřeší, zda je zastaralý, sekundární nebo jinak omezený.

## Vhodné použití v práci

- Kapitoly nebo typy tvrzení, pro které je zdroj vhodný.
```
