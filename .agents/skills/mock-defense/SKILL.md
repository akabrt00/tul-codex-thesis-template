# Mock Defense

## Build the question base

Read the actual thesis, assignment, objectives, methods, results, limitations, presentation, and available reviews. Identify genuine tension points: method choice, uncertainty, validity, reproducibility, interpretation, contribution, alternatives, source quality, and opponent questions. Do not substitute a generic examination list for project-specific evidence.

## Run the interaction

Ask exactly one question, wait for the student's answer, then evaluate it against the project material. For each answer:

1. identify what was strong;
2. identify what was unsupported, unclear, omitted, or overstated;
3. cite the relevant project location when available;
4. propose a tighter answer structure without inventing facts;
5. ask the next question only after the feedback.

Vary difficulty and distinguish questions answerable from the thesis from those that need the student or supervisor. Never invent a canonical answer when project evidence does not support one.

## Summarize progress

On request or after a reasonable round, summarize recurring strengths, vulnerable topics, unsupported answers, and concrete rehearsal tasks. This skill does not edit thesis or presentation files; if the user requests material changes, route them through the applicable skill and `$review-agent-output`.
