# Inter pro připravenou prezentaci

Čtyři nezměněné statické řezy Inter jsou distribuovány pod SIL Open Font License
1.1; úplný text a autorství jsou v `LICENSE.txt`. Původní projekt:
https://github.com/rsms/inter a https://rsms.me/inter/.

Soubory byly převzaty 6. 10. 2026 z již připraveného komunitního cvičného balíčku
TUL × LaTeX `tulpresentation-cvicna-2026-10-04.zip`. Názvy souborů slouží k
načítání přes fontspec; binární obsah fontů nebyl upravován.
Inicializátor je kopíruje do pracovní složky `obhajoba/fonts/` spolu s licencí.
Není potřeba instalovat Inter do systému. Původní TUL Mono zůstává v balíčku
TULpresentation a tato složka nemění `templates/upstream/`.
